# wandering-pencils-pins

Pinterest pin images for Wandering Pencils activity packs. Each pack has three pins:

```
pins/<slug>/pin1.png
pins/<slug>/pin2.png
pins/<slug>/pin3.png
```

Raw URLs:

```
https://raw.githubusercontent.com/tanzil4code/wandering-pencils-pins/main/pins/<slug>/pin1.png
```

Packs: `bundle`, `christmas-family-game-pack`, `christmas-travel-activity-pack`, `travel-coloring-pack`, `travel-counting-matching-logic-pack`, `travel-dot-to-dot-tracing-pack`, `travel-games-fun-pack`, `travel-mazes-pack`, `travel-spot-the-difference-seek-and-find-pack`, `travel-word-search-pack`.
